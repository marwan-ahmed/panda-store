## 1. Assets
- **Catalog-Authoritative IQD Pricing & Total Integrity:** Fixed positive integer unit prices in `src/lib/products.ts#PRODUCTS` (`"1"`–`"10"`), exact integer line subtotals (`lineSubtotalIqd = product.priceIqd * quantity`), and exact integer cart grand totals (`cartTotalIqd`, `"0 د.ع"` when empty, `19,899,000 د.ع` max across all 10 items × `99`) with zero decimals, rounding errors, delivery fees, taxes, discounts, or client-supplied price overrides (`EXEC_PROMPT.md` R3, R6; `AGENTS.md`).
- **Cart Quantity & State Invariants:** Strict positive integer quantities in `[1, 99]` (`MIN_CART_QUANTITY`..`MAX_CART_QUANTITY`), non-destructive rejection of invalid inputs, single-line deduplication per `productId` clamped at `99`, and atomic consistency between `SiteHeader` counter (`itemCount`), `AddToCartButton`, `CartView`, and `window.localStorage` (`panda-store:cart:v1`) across Next.js 16 `<Activity>` route preservation and cross-tab `storage` events (`EXEC_PROMPT.md` R1–R5, R8).
- **Browser Storage & DOM Execution Integrity:** Protection against tampered `localStorage` payloads, JSON prototype pollution (`__proto__`), stored/DOM XSS payloads, oversized-storage DoS, and runtime crashes (`SecurityError` / `QuotaExceededError` / malformed JSON / React hydration mismatches) (`EXEC_PROMPT.md` R3, §7; `DECISIONS.md` ADR-5).
- **Zero-Server / Zero-Checkout / Zero-PII Scope Boundary:** Guarantees that no server cart endpoints (`src/app/api/**`), `"use server"` Server Actions, `cookies()`/`Set-Cookie` sessions, checkout/order forms, customer PII fields (name, phone, address), payment gateways/keys, or login/auth surfaces are introduced (`EXEC_PROMPT.md` R10, §5, §7; `AGENTS.md`).

## 3. Trust boundaries
1. **Untrusted Browser Storage (`window.localStorage["panda-store:cart:v1"]` & `storage` Events) ↔ `cart-storage.ts` / `cart-store.ts`:** Everything read from `localStorage` (or synced via cross-tab `storage` events) is treated as attacker-controlled text. Size (`MAX_CART_STORAGE_BYTES = 65536`), array length (`MAX_RAW_STORAGE_ITEMS = 200`), schema version (`version === 1`), JSON syntax, own-property allow-lists (`productId`, `quantity`), linear catalog ID lookup (`getProductById`), duplicate merging, and quantity bounds (`1..99`) are enforced before any state enters `Cart` or UI components, and `CartProvider` repairs dirty payloads on mount.
2. **Untrusted UI Inputs & Callers ↔ Pure Domain Layer (`src/lib/cart.ts`):** Direct calls to `addToCart`, `updateCartQuantity`, `incrementCartItem`, `decrementCartItem`, `removeFromCart`, `sanitizeCartItems`, `buildCart`, `validateCartQuantity`, `parseQuantityInput`, and `formatCartTotalIqd` cross from DOM inputs/client callers into monetary and quantity logic. All inputs fail closed without type coercion, rounding, prototype lookup, or mutation of prior valid state.
3. **Static Server Prerender / Cache Components (`next.config.ts`) ↔ Client Store Hydration (`cart-store.ts`):** With `cacheComponents: true` and `partialPrefetching: true`, `RootLayout` and `src/app/cart/page.tsx` execute on the server/prerender layer, while client routes may be hidden/restored inside React `<Activity>`. `getServerCartSnapshot()` must always return the static frozen `EMPTY_CART` so server HTML/RSC payloads never read or cache per-visitor state and never mismatch initial client hydration.
4. **Catalog Boundary (`src/lib/products.ts` & `src/proxy.ts#proxy`) ↔ Storefront Components:** `src/lib/products.ts` (`validatePriceIqd > 0`, `formatPriceIqd > 0`, `PRODUCTS`) and `src/proxy.ts` (`404` on invalid `/products/*`) remain untouched; `formatCartTotalIqd` (`>= 0`) lives separately in `src/lib/cart.ts` (`DECISIONS.md` ADR-6) so `TASK-001` invariants cannot regress.

## 5. Abuse cases
Priority order: access control, auth & scope boundaries first, then money/price/quantity integrity, then prototype pollution & XSS injection, then mass assignment & error/quota resilience, then resource abuse & configuration/caching/supply chain.

- **AB-1** (axis: `access_control` · entry: `GET /cart`, `GET /products/[id]`, `src/app/**`, `src/components/**` · ref: OWASP A01:2025, ASVS 5.0 V4 · → T3, T4, T5 · SPEC: AC-6, AC-9):
  An attacker inspects the codebase, routes, and rendered DOM of `/`, `/products/[id]`, and `/cart`, and probes `GET /products/cart`, `GET /products/99`, and `GET /cart/checkout` looking for unintended server-side mutation APIs (`src/app/api/**/route.ts`), `"use server"` Server Actions, checkout or order-submission `<form>`s, customer data inputs, payment/COD execution buttons, discount/coupon/search controls, or broken `proxy.ts` `404` guards.
  *(Note: multi-tenant isolation and role-based access checks are N/A because TASK-002 has zero user accounts, roles, or server-side cart persistence.)*
  **Expected secure behaviour:** Zero `src/app/api/**` route handlers and zero `"use server"` directives exist; `/`, `/products/[id]`, and `/cart` render zero `<form>` elements, zero checkout/COD/payment/discount/coupon/search/stock UI, and zero customer PII inputs; `src/proxy.ts#proxy` continues rewriting `/products/cart` and `/products/99` to `/__not-found` with HTTP `404` and zero leaked paths.

- **AB-2** (axis: `authentication` · entry: `src/app/layout.tsx#RootLayout`, `src/app/cart/page.tsx`, `src/lib/cart-storage.ts`, `src/lib/cart-store.ts` · ref: OWASP A07:2025, ASVS 5.0 V7 · → T2, T3, T5 · SPEC: AC-7, AC-9):
  An attacker inspects all source modules, HTTP responses/headers, and rendered cart components for `cookies()` reads, `Set-Cookie` headers, or login/registration/password UI, and plants synthetic credential fields (`{ version: 1, items: [{ productId: "1", quantity: 1 }], token: "fake-jwt", sessionId: "abc", password: "123" }`) inside `localStorage["panda-store:cart:v1"]`.
  **Expected secure behaviour:** Zero `cookies()` calls, zero `Set-Cookie` headers, and zero login/signup/password UI exist anywhere in the storefront; `parseStoredCart` and `repairStoredCartIfNeeded` ignore and purge any injected auth/session fields so `localStorage["panda-store:cart:v1"]` stores strictly `{ version: 1, items: [{ productId: "1", quantity: 1 }] }`.

- **AB-3** (axis: `business_logic` · entry: `src/lib/cart-storage.ts#parseStoredCart`, `src/lib/cart.ts#sanitizeCartItems`, `src/lib/cart.ts#buildCart`, `src/components/cart-view.tsx#CartView` · ref: OWASP A06:2025, ASVS 5.0 V2/V5 · → T1, T2, T3 · SPEC: AC-5, AC-8, EC-5):
